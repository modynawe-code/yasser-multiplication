# اتفاق تفاعل احتكار المعرفة

النطاق: تطوير اللعبة الحالية على feature/product-ui-reference-v1؛ الحفاظ على أصل البورد وبطاقات الملكية. القواعد والنتائج من المحرك/الخادم؛ العرض لا يولد نتيجة ثانية.

| ID | المتطلب ومعيار القبول |
|---|---|
| DICE-01 | مكعبان بستة أوجه فعلية وعمق ثلاثي الأبعاد. |
| DICE-02 | دوران متعدد المحاور وتقليب الأوجه ثم الاستقرار على نتيجة المحرك الصحيحة 1–6. |
| DICE-03 | ارتداد وظل واصطدام متزامن؛ استجابة مباشرة للمسة. |
| DICE-04 | صوت رمي واصطدام بعد فتح الصوت بلمسة؛ زر كتم واضح. |
| DICE-05 | الضغط أو السحب والإفلات يرمي مرة واحدة؛ يمنع تكرار الطلب. |
| MOVE-01 | إصلاح CSS المجسم؛ مجسم واضح يتحرك خطوة بخطوة. |
| MOVE-02 | تثبيت نتيجة الرمية ثم بدء الحركة دون انتظار فارغ 1.3 ثانية. |
| CAMERA-01 | لوحة كاملة في الانتظار وبعد الحدث. |
| CAMERA-02 | تقريب وتتبع المجسم خلال الحركة؛ تقريب الخانة عند الحدث. |
| CAMERA-03 | انتقال سلس مع حد يمنع خروج اللوحة؛ عودة سلسة بعد الحدث. |
| CAMERA-04 | دعم تكبير بإصبعين وسحب اللوحة ونقر مزدوج لإعادة الضبط. |
| CARD-01 | إبراز الفرصة/الجماعة عند الوصول؛ اختيار الرزمة المناسبة بالضغط. |
| CARD-02 | سحب بطاقة إلى الساحة ثم الضغط لقلبها وكشف محتواها. |
| CARD-03 | تأكيد منفصل لتطبيق الأثر؛ لا تطبيق تلقائي عند السحب/القلب. |
| MONEY-01 | ترتيب وصول ← سبب ← حركة مبلغ وصوت ← رصيد جديد. |
| MONEY-02 | توضيح الدافع والمستلم والرصيد قبل/بعد؛ ترحيل مالي بصري. |
| MONEY-03 | أصوات مميزة للدفع والاستلام والشراء والسحب والخطوات. |
| OWN-01 | تأثير شراء على الخانة بلون المالك ثم إظهار أملاكه. |
| OWN-02 | ظهور البيوت/الفندق مع تأثير بناء وتحديث الملكية. |
| TURN-01 | إعلان واضح للاعب صاحب الدور؛ اختلاف انتظار الخصم عن دورك. |
| END-01 | عرض مخصص للفوز والإفلاس؛ عدم تعطيل الخروج/بدء جولة أخرى. |
| TRADE-01 | اقتراح ثم قبول/رفض من الطرف المعني قبل انتقال الأرض/المبالغ. |
| TRADE-02 | الخادم يرفض موافقة غير المستلم؛ إعادة التحقق من الرصيد/الملكية. |
| UI-01 | بطاقات لاعبين قريبة من اللوحة؛ لا فراغ طولي واسع؛ هدف لمس 44px. |
| UI-02 | الساحة ثابتة أثناء تكبير البورد؛ البطاقة والأزرار مقروءة. |
| ONLINE-01 | نتائج النرد والبطاقة ومراحل السحب والتبادل من الخادم وتظهر للطرفين. |
| ONLINE-02 | منع إعادة نفس الحدث أثناء polling؛ عدم قطع حركة جارية بسبب snapshot. |
| ONLINE-03 | التحكم لصاحب الدور، وموافقة التبادل للمستلم فقط. |
| A11Y-01 | لوحة مفاتيح/وصف الأزرار وإعلان الحالة؛ احترام تقليل الحركة. |
| SAFE-01 | إلغاء الحركة والصوت المؤجل عند مغادرة اللعبة/إعادة التشغيل. |

## الإثبات
كل بند يحتاج مسار الكود ودليل اختبار. نجاح اختبارات المحرك لا يثبت الصوت أو المظهر. يسجل الاختبار غير المتاح صراحة. لا يعد بند مختبرًا على جهاز حقيقي إلا بعد تنفيذه عليه.
