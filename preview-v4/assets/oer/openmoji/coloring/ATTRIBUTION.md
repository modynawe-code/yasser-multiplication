# OpenMoji coloring-page source

The line-art SVG files in this folder are adapted from **OpenMoji** black SVG graphics.

- Source: https://github.com/hfg-gmuend/openmoji
- License: Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0)
- License text: https://creativecommons.org/licenses/by-sa/4.0/
- Use in this project: child-friendly Arabic letter coloring activities.
- The SVGs are stored locally for offline use.
- The surrounding Arabic curriculum, activity flow, and UI are authored in this project.

Files used in the first coloring batch:
- rabbit.svg — OpenMoji U+1F407
- duck.svg — OpenMoji U+1F986
- crocodile.svg — OpenMoji U+1F40A
- fox.svg — OpenMoji U+1F98A
- camel.svg — OpenMoji U+1F42B
