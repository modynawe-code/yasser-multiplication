# Mashaal KG3 module

Mashaal is a Saudi KG3 learner profile, not a copy of the Grade 1 or multiplication flows.

Authoritative curriculum anchor:
- Saudi Ministry of Education / National Curriculum Center, Curriculum Guide Fifth Edition (2025).
- KG3 is level three (ages 5–6) and includes six learning domains.
- Activity design follows developmentally appropriate, play/inquiry-oriented early-learning practice.

Implementation rules:
1. Keep learner identity separate from curriculum and progress data.
2. Keep child-facing grading qualitative; detailed analytics remain parent-facing.
3. Prefer listen/look/choose-manipulate/feedback/transfer interactions over text-heavy testing.
4. Support off-screen guided-play transfer activities.
5. Do not hard-code Mashaal into shared engines; register the learner and curriculum instead.
6. Any Quran/Islamic or Saudi-specific content must be verified against an authoritative source before release.
